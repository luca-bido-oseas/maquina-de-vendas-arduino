# Máquina de Vendas Automática (Protótipo)

Protótipo funcional de máquina de vendas automática desenvolvido com **Arduino** e programado em **C**, simulando a seleção de produtos e o acionamento do mecanismo de liberação.


## Funcionalidades
- Seleção de produtos por botões
- Acionamento do mecanismo de liberação
- Exibição de informações em display

## Componentes utilizados
- Arduino
- Teclado de membrana 1x4
- Display de LCD
- Mecanismo de liberação com motores e molas

## Como funciona
1. O usuário seleciona o produto pelo botão correspondente
2. O display mostra a seleção
3. O usuário confirma a seleção do produto
4. O mecanismo de liberação é acionado para entregar o produto

## Aprendizados
- Lógica de programação aplicada a hardware
- Controle de entradas e saídas digitais
- Integração de componentes eletrônicos

## Tecnologias
- C
- Arduino
